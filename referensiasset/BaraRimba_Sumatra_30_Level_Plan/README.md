# BaraRimba Sumatra — 30 Level

Paket perencanaan konten untuk memperluas game Jawa yang sudah ada.

- `config/sumatra-30-levels.json`: data terstruktur untuk 30 level.
- `docs/sumatra-30-level-plan.md`: desain misi, tujuan, progresi kesulitan, dan aturan implementasi.

Penting: ini adalah rencana konten. Tidak ada source game Jawa di dalam ZIP, dan level belum diimplementasikan atau diuji di engine. Saat integrasi, petakan nama asset dan schema konfigurasi ke struktur repository yang sebenarnya. Jangan mengganti sistem semburan yang sudah berjalan.
